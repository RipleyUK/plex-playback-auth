Plex Playback privacy policy

Updated 20 September 2026.

Plex Playback is a private integration for the operator's personal media server. It accesses Google Drive file metadata and file contents, including files shared with an authorised account, to locate, stream, cache and manage the personal media library.

Google authorisation tokens are stored in access-restricted configuration files and backups controlled by the operator. File contents may be temporarily cached on the media server; library metadata and operational logs may be retained for playback and troubleshooting. This application does not sell Google user data, use it for advertising, or use it to train AI models. Data is used only for the personal media integration and made available through the operator's configured media-server access.

Account owners can revoke the application's access in their Google Account third-party connections settings at any time. The operator can remove stored credentials, logs and cached data. Revoking access does not itself delete existing copies or the original Drive files.

Contact the operator through the support email shown on the Google consent screen. This informational site has no application sign-in, analytics scripts or media files; its hosting provider may process normal web-server request information.

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
